# Blogger integration (optional)

For a public admission page, add this iframe to a Blogger HTML view:

```html
<iframe src="https://sonarbanglaadarshoschool.github.io/sbas-school-management/admission.html" width="100%" height="1600" style="border:0" loading="lazy" title="SBAS Online Admission"></iframe>
```

Do not embed or publish the admin dashboard as an unrestricted public page. Firebase authentication and Firestore rules remain required.
